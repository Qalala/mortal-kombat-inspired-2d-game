# Assets are not included in this repository (third-party / copyrighted game media).

Copy your local Assets folder here so the layout matches the game's expected paths, e.g.:
- Assets/Characters/Scorpion/Sprites/...
- Assets/Characters/Scorpion/Sounds/...
- Assets/Characters/Subzero/...
- Assets/Images/...

After placing files, build/run so Assets resolve from the output directory.
